#### 冠軍聯賽功能細節
- Supabase 新增 `champion_matches` 表（已執行建表 SQL）
- 注單彙總沿用既有 `tickets_aggregate` 表（match_id 以 `champ_` 前綴自然隔離）
- 表格標題顯示「世界盃足球」，欄位結構與棒球賽事相同
- 編輯模式：
  - 「+ 新增賽事」按鈕插入空白列
  - 每列「✕」按鈕刪除賽事
  - 編號、隊名、時間、所有賠率/讓分線均可點擊 inline 編輯
  - 編號修改有重複驗證，重複時跳出錯誤通知

#### 查詢報表分組加總邏輯
- **編輯模式**：顯示全部個別記錄，可見 / 編輯每筆的起始 / 結束日期
- **查看模式**：相同 `site_name` 的多筆記錄自動合併為一列並加總數值
  - 點擊「查詢」後依篩選日期範圍過濾，再分組加總
  - 未篩選時（初始載入）也分組加總所有記錄
