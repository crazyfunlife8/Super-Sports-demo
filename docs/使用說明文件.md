# 網站使用說明 / 編輯模式使用手冊

## 一、系統總覽

本平台為棒球賽事投注資料展示系統，共三個頁面，搭配一組編輯模式供後台人員管理資料。

| 頁面 | 檔案 | 功能 |
|------|------|------|
| 首頁（網站業績報表） | `index.html` | 顯示各子網站投注業績，含7個階級盈虧數據 |
| 即時注單 | `live-bets.html` | 顯示未來24小時內賽事的即時注單分布，每11秒自動更新 |
| 歷史賽事 | `history.html` | 顯示已開賽/已結束的賽事注單彙總與比分結果 |

---

## 二、一般使用者操作

### 首頁（網站業績報表）

- 開啟 `index.html` 即可查看各網站當期業績
- 點擊「▶」箭頭可展開/收合各階級的返水欄位
- 頁面底部顯示「合計」加總列
- 跑馬燈顯示最新公告文字

### 即時注單頁

- 開啟 `live-bets.html` 查看今日賽事注單
- 上方導覽列切換球種（美棒 MLB / 台棒 CPBL / 日棒 NPB）
- 右上角顯示倒數秒數，每 **11 秒**自動重新整理資料
- 點擊「立即更新」按鈕可手動刷新
- 各欄位說明：
  - **讓分 / 注單**：盤口線、賠率、注數/注金
  - **大小盤 / 注單**：大小線、賠率、注數/注金
  - **獨贏**：主客賠率、注數/注金
  - **單雙**：賠率、注數/注金
  - **一輸二贏**：半場讓分盤口、賠率、注數/注金

### 歷史賽事頁

- 開啟 `history.html` 查看已開賽/已結束賽事
- 每場賽事分兩列：**[全場]** 和 **[半場]**
- **[全場]**：顯示全場比分、全場各盤口注單
- **[半場]**：顯示半場（前5局）比分、半場讓分/大小/獨贏注單
- 比分欄顯示「主:客」格式，未結束賽事顯示 `—`

## 三、進入編輯模式

### 進入方式

在任一頁面的 URL 結尾加上 `?edit=true`：

```
index.html?edit=true
live-bets.html?edit=true
history.html?edit=true
```

進入後：
- 頁面右上角出現紅色「編輯模式」標示
- 右側出現操作按鈕面板
- 可編輯的欄位以紅色字體或底線提示
- **URL 保持顯示 `?edit=true`**，重新整理頁面後編輯模式仍保留

### 退出方式

點擊右側面板的「**退出編輯模式**」按鈕，頁面自動跳回一般檢視模式。

## 四、編輯模式功能說明

### 4-1 頁首資訊編輯

在編輯模式下，頁首的帳號名稱、身份、額度均可點擊直接修改：

1. 點擊要修改的文字（帳號 / 身份 / 額度）
2. 文字變成輸入框，直接輸入新值
3. 按 **Enter** 儲存，按 **Esc** 取消
4. 儲存後自動同步至 Supabase，其他裝置的畫面會即時更新

### 4-2 跑馬燈文字編輯

1. 點擊跑馬燈文字區域
2. 跳出編輯視窗，可輸入多行文字（每行為一段公告）
3. 點擊「**儲存**」按鈕
4. 多行內容以空格自動串接，並同步至 Supabase

### 4-3 網站業績資料編輯（首頁）

在首頁編輯模式下：

**修改欄位值：**
1. 點擊任一資料格（顯示底線或字體變色）
2. 欄位變為輸入框
3. 輸入新數值，按 **Enter** 儲存，按 **Esc** 取消
4. 數字欄位自動去除逗號，轉為整數儲存

**新增網站列：**
1. 捲動至表格底部
2. 點擊「**+ 新增網站**」按鈕
3. 新列以預設值插入，再逐欄點擊修改

**刪除網站列：**
1. 每列最左欄出現垃圾桶圖示
2. 點擊垃圾桶 → 確認對話框 → 確定即刪除（無法復原）

### 4-4 注單資料編輯（即時注單頁 / 歷史賽事頁）

注單欄位的注數（紅色）和注金可直接點擊修改：

1. 點擊紅色注數或注金數字
2. 輸入框出現，輸入新值
3. 按 **Enter** 儲存，按 **Esc** 取消
4. 儲存後呼叫 Supabase upsert（有則更新，無則新增）

### 4-5 右側操作面板

| 按鈕 | 功能 |
|------|------|
| 退出編輯模式 | 離開編輯模式，回到一般檢視 |
| 匯出 JSON | 將目前 sites、tickets_aggregate、matches 三張表資料下載為 JSON 備份檔 |
| 匯入 JSON | 上傳 JSON 檔案，覆蓋 sites 和 tickets_aggregate 資料（matches 不覆蓋） |
| 立刻同步 API | 立即觸發 Edge Function，從 SportsGameOdds API 拉取最新賽事與賠率 |
| 批量隨機填注單 | 為所有賽事生成隨機注單資料（demo 展示用） |
| 清空注單彙總 | 刪除 tickets_aggregate 全部資料（無法復原） |
| 清空網站業績 | 刪除 sites 全部資料（無法復原） |
| 重置預設資料 | 清空所有資料並還原預設示範資料 |

## 五、資料同步說明

| 功能 | 同步方向 | 說明 |
|------|---------|------|
| 跑馬燈 / 頁首資訊 | 雙向即時（Realtime） | 任一視窗修改，所有連線視窗即時更新 |
| 注單資料 | 儲存後手動刷新 | 點擊欄位儲存後，頁面自動 Refresh 一次 |
| 網站業績 | 儲存後手動刷新 | 修改後頁面自動 Refresh |
| 賽事/賠率 | 按需手動同步 | 點擊「立刻同步 API」或設定排程自動同步 |

## 六、常見問題

**Q: 重新整理後編輯模式消失了？**  
A: 檢查 URL 是否仍有 `?edit=true`。若沒有，重新在 URL 後加上 `?edit=true` 即可。

**Q: 點擊注單數字沒有反應？**  
A: 確認目前是在編輯模式（URL 有 `?edit=true`，右上角顯示「編輯模式」）。若是，嘗試點擊「退出編輯模式」再重新進入。

**Q: 立刻同步 API 要等很久？**  
A: 正常現象。Supabase Edge Function 首次呼叫需冷啟動（5～15 秒），再加上 API 請求時間，總計約 15～25 秒。後續連續呼叫會較快。

**Q: 即時注單頁的賽事太多/太少？**  
A: 即時注單只顯示未來 24 小時內的未結束賽事。若賽事較少，可能是當日無賽事或 API 尚未同步。

**Q: 歷史賽事比分顯示「—」？**  
A: 表示該賽事尚未結束，或 API 尚未回傳比分。待賽事結束並同步後會自動補上。
